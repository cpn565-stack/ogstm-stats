  cd /home/deploy/ogstm-stats &&
  git pull &&
  npm ci &&

### 3.2 更新前備份資料

```bash

   /home/deploy/ogstm-backups/store-manual-$(date +%F-%H%M).json
```

### 3.3 Vertex OAuth 憑證更新（過期時）

```bash

cd /Users/mike/ogstm-stats
npm run setup:vertex-oauth

# 上傳至 VPS

  root@165.232.161.37:/home/deploy/.gcp/adc.json

ssh root@165.232.161.37 \
  "chown deploy:deploy /home/deploy/.gcp/adc.json && chmod 600 /home/deploy/.gcp/adc.json && sudo -u deploy pm2 restart ogstm-stats"
```

## 四、拍照 AI 辨識（2026-06-25 新增）

### 4.1 使用方式

1. 開啟 `/session/:id/photo`
2. 選 **Gemini 3.5 Flash** 或 **Nemotron VL**
3. **拍照** 或 **選擇照片**
4. 等待 AI 預填（約 5–15 秒）
5. **逐項確認**綠/紅勾選後儲存

### 4.2 產品規則

| 項目 | 規則 |
|------|------|
| G 卷 | 14 項 a–n；綠 = 最重要、紅 = 最易忽略 |
| T 卷 | 10 項 a–j；綠 = 最重要、紅 = 最不易執行 |
| 每格票數 | **0 或 1**（非贊成/反對計數） |
| 儲存前 | 必須人工確認（AI 可能出錯） |

### 4.3 API

```
POST /api/recognize
Content-Type: application/json

{
  "questionId": "vote_1",
  "imageBase64": "...",
  "mimeType": "image/jpeg",
  "provider": "vertex"
}
```

### 4.4 GCP 專案

| 項目 | 值 |
|------|-----|
| Project ID | `ogstm-input` |
| Vertex 區域 | `asia-southeast1` |
| 模型 | `gemini-3.5-flash` |
| 認證 | OAuth ADC（非 Service Account JSON） |

## 九、常見問題

### 拍照顯示「伺服器錯誤」或英文 JSON 錯誤

- 重新整理頁面後再試
- 改選 **Nemotron VL** 測試 OpenRouter
- 檢查 Vertex：`GOOGLE_APPLICATION_CREDENTIALS` 檔案是否存在
- `pm2 logs ogstm-stats --lines 50`

### Gemini 報認證錯誤

重新執行「3.3 Vertex OAuth 憑證更新」。

### 手動輸入仍是最穩定方式

課堂若 AI 太慢或不準，直接用 `/manual`。
