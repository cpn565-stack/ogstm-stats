## 二、完成功能

### 2.1 拍照 AI 辨識（雙 Provider）

| Provider | 模型 | 用途 |
|----------|------|------|
| **Vertex AI** | `gemini-3.5-flash` | 預設；GCP 專案 `ogstm-input` |
| **OpenRouter** | `nvidia/nemotron-nano-12b-v2-vl:free` | 備援／零成本測試 |

- API：`POST /api/recognize`（body 可帶 `provider: "vertex" | "openrouter"`）
- 相容舊路徑：`POST /api/recognize/openrouter`（固定 OpenRouter）
- 拍照頁可切換：**Gemini 3.5 Flash** / **Nemotron VL**
- 流程：上傳照片 → AI 預填綠/紅（0 或 1）→ **助教必須確認** → 儲存

### 2.2 手機拍照體驗

| 項目 | 說明 |
|------|------|
| **拍照 / 選擇照片** | 拆成兩個按鈕（相機 vs 相簿） |
| **上傳前壓縮** | 最長邊 1600px、JPEG，避免超過 Nginx 限制 |
| **錯誤訊息** | Safari JSON 解析失敗改為中文說明 |
| **Nginx** | `client_max_body_size 20m`、`proxy_read_timeout 120s` |

### 2.3 票數邏輯修正

- 拍照自動辨識改為**每格只有 0 或 1**（修正舊版 0–3 票 bug）
- 與手動輸入、紙本規則一致：綠格 = 最重要、紅格 = 最易忽略（T 卷紅格 = 最不易執行）

### 2.4 GCP / Vertex AI 設定

| 項目 | 值 |
|------|-----|
| GCP 專案 | `ogstm-input` |
| 區域 | `asia-southeast1` |
| 模型 | `gemini-3.5-flash` |
| 認證方式 | OAuth Application Default Credentials（ADC） |
| VPS 憑證路徑 | `/home/deploy/.gcp/adc.json` |
| 本機設定腳本 | `npm run setup:vertex-oauth` |

> 組織政策禁止建立 Service Account JSON 金鑰，故採 **OAuth ADC**，非 SA key。
